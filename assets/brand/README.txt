PIQA LOGO KIT v1
================
Colors: ink #141210 · paper #F2EDE4 · safelight #FF5A36
Rule: the safelight dot is always singular. Never two dots, never recolored
(sole exception: gold #E3B341 on the Photo-of-the-Day share card).
Clear space: one bracket-arm width around the mark.

app/
  piqa-icon-512.svg            Play Store icon (512, rounded dark)
  piqa-icon-safelight-512.svg  Alt icon / marketing tile (orange field)
  piqa-adaptive-foreground.svg Android adaptive FG (mark in 66% safe zone)
  piqa-adaptive-background.svg Android adaptive BG (solid ink)

mark/
  piqa-mark.svg                Paper strokes + safelight dot (dark surfaces)
  piqa-mark-ink-safelight.svg  Ink strokes + safelight dot (light surfaces)
  piqa-mark-ink.svg            One-color ink (print, engraving, embroidery)
  piqa-mark-paper.svg          One-color paper (dark fabric merch)

social/
  piqa-social-avatar-1024.svg  Profile avatar, circle-crop safe (TikTok/IG/X)

marketing/
  piqa-lockup.svg              Mark + wordmark, transparent, dark surfaces
  piqa-og-banner-1200x630.svg  Link-preview / OG banner with tagline
  piqa-sticker-gts.svg         "got the shot?" stamp

NOTE ON TYPE: lockup/banner/sticker reference "Clash Display" by name.
Before final export, install Clash Display (free at fontshare.com) and
convert text to outlines (Figma: right-click > Outline stroke / Inkscape:
Path > Object to Path) so the SVG is font-independent. The mark files are
production-final as-is.
